Model Workflow

How the System Works

1
Input and PreprocessingThe tomato plant image is uploaded, resized, normalized, and prepared for inference.
2
CNN Feature LearningThe CNN branch learns local visual patterns such as leaf shape, texture, and edge structure.
3
Transformer Context LearningThe Transformer branch captures global contextual relationships across the full plant image.
4
Fusion and ClassificationThe model fuses local and global features and predicts the final tomato growth stage.

Proposed Architecture

Hybrid CNN-Transformer Feature Learning

The same preprocessed tomato image is analyzed by two complementary branches. Their representations are concatenated before the final growth-stage decision.

Input Image RGB, 224 x 224
→
CNN Branch 3 convolution blocks learn local shape, texture, and edge features. Output: 128-D.
Transformer Branch 196 patches, CLS token, and 2 encoder layers learn global context. Output: 128-D.
→
Feature Fusion Concatenate local and global representations into a 256-D vector.
→
Classifier Fully connected layer, ReLU, dropout, and two-class output.
→
Growth Stage Early Vegetative or Flowering Initiation
Local feature learning Global context learning Joint feature representation

Research Reflection

Limitations and Future Work

Current limitations
The current study focuses on only two early tomato growth stages and uses a relatively small dataset. Some invalid image files were excluded during experimentation, and the current browser demo is intended for local academic presentation rather than large-scale deployment.
Future work
Future work can expand the dataset, include more tomato varieties and growth stages, repeat evaluation across field locations and seasons, and validate the uncertainty and heatmap outputs with agricultural experts.
